🔊 Conserver un enregistrement (facultatif)
Racontez librement une idée ou une histoire. L’enregistrement restera associé à ce texte et sera inclus dans votre sauvegarde JSON.
Le microphone nécessite votre autorisation et une page HTTPS (ou localhost). Les audios augmentent la taille du JSON.
Les modifications sont enregistrées automatiquement dans ce navigateur. Pour protéger vos textes et les transférer entre iPhone et PC, utilisez régulièrement Sauvegarder JSON et conservez ce fichier dans iCloud Drive ou un autre dossier sûr. Une navigation privée ou l'effacement des données du navigateur peut supprimer la copie locale.

Réglages
Les textes sont enregistrés automatiquement sur cet appareil. Pour les protéger ou les retrouver sur un autre appareil, exportez une copie JSON dans iCloud Drive. Le navigateur ne peut pas remplacer automatiquement un fichier iCloud existant.
Sur iPhone : écrivez, puis touchez Enregistrer sur iPhone et choisissez Enregistrer dans Fichiers → iCloud Drive. Vous pourrez ensuite importer ce JSON sur PC. La sauvegarde automatique locale ne synchronise pas les appareils. Les enregistrements vocaux sont inclus dans le JSON et peuvent rendre le fichier volumineux.
