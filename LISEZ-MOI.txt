L’Atelier des mots V1.4 — iPhone en priorité

1. AVANT TOUT : dans la version actuelle, exportez votre bibliothèque JSON et conservez-la dans iCloud Drive.
2. Dans GitHub FJP6/atelier-des-mots, remplacez uniquement index.html à la racine de main.
3. Attendez GitHub Pages, puis rechargez Safari.
4. Testez Écrire, Dicter (micro du clavier iPhone), Tous mes textes, Rubriques, Réglages.

Sauvegarde automatique locale : même clé que les versions précédentes. Le fichier atelier-des-mots.json est exporté avec un nom fixe, mais iOS peut créer une copie ou demander confirmation, et aucun écrasement iCloud automatique n’est possible.
La dictée via clavier iOS nécessite que le clavier soit affiché ; le bouton de transcription Web peut être indisponible dans Safari.
La sauvegarde n’est pas synchronisée entre appareils.
